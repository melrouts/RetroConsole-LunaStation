# ESP32-приёмник и MAX98357A

Все схемы в этой папке показывают одну актуальную распиновку:
**LRC → IO25, BCLK → IO32, DIN → IO22**.

- [Схема по фотографии со стороны пайки](esp32-max98357a-back-photo-wiring.png)
  ([SVG](esp32-max98357a-back-photo-wiring.svg)).
- [Схема по фотографии со стороны компонентов](esp32-max98357a-photo-wiring.png)
  ([SVG](esp32-max98357a-photo-wiring.svg)).
- [Общая схема соединений](esp32-max98357a-wiring.png)
  ([SVG](esp32-max98357a-wiring.svg)).

Исходные фотографии плат находятся в `photos/`. Питание, подключение динамика,
проверка и ограничения описаны в
[инструкции по сборке](../../docs/04_ASSEMBLY_AND_CONNECTIONS.md#7-audio);
прошивка и команды — в [описании ESP-NOW](../../examples/espnow-counter/README.md#receiver-audio-max98357a).
Использование звука из программ и текущие ограничения — в
[плане ПО](../../docs/09_SOFTWARE_PLAN.md).
Новая игровая сборка синтезирует музыку и эффекты на приёмнике; пользователь
подтвердил музыку и тягу в игре и громкость демонстрации эффектов.
