# Memorial image credits

- `luna9-capsule.jpg` is a resized copy of
  [Luna-9 Space Probe Descent Capsule](https://commons.wikimedia.org/wiki/File:Luna-9_Space_Probe_Descent_Capsule.jpg)
  by Stolbovsky, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
  The original photograph shows the capsule in a museum. For the FPGA display,
  the build additionally scales it and converts it to four grayscale tones.
- `apollo11-nasa-6900956.jpg` is a NASA image of Buzz Aldrin and the Apollo 11
  lunar module, photographed by Neil Armstrong. The
  [NASA image record](https://images.nasa.gov/details/6900956) and
  `apollo11-nasa-6900956.json` contain the source metadata.
